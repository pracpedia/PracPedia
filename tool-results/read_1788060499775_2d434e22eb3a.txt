   660→  1. The user opens the page from the z.ai preview gateway

   662→  3. The OLD HTML references OLD JS chunks by their old hashes
   663→  4. After server restart, those old chunk files no longer exist on disk
   664→  5. The browser tries to load the old chunk → 404 → ChunkLoadError
   665→  6. React never hydrates → the loading screen persists forever
